# LidiTax — regras do repositório

## Commits e publicação (Netlify, plano gratuito)
- A Netlify só publica commits de **um** contribuidor verificado em repositório privado.
- Autor e committer de todo commit: `lukasgomeseliteconsultores-svg <288044615+lukasgomeseliteconsultores-svg@users.noreply.github.com>`.
- **Não** incluir a linha `Co-Authored-By:` na mensagem: o coautor conta como segundo contribuidor e a Netlify bloqueia o build ("unrecognized Git contributor"). A linha `Claude-Session:` pode ficar.
- Entregas por commit no `main` (nunca zip). Site: https://liditax.netlify.app
